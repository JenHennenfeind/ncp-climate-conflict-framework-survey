# ncp-climate-conflict-framework-survey
Data, coding tables and R scripts for Hennenfeind et al., A Framework for Integrating Biodiversity and Nature’s Contributions to People into the Climate–Conflict Nexus (manuscript submitted to BioScience, October 2026).

The scripts read extraction_temp_ANALYSIS_26-07-06.xlsx from the project root; this file is available from the corresponding author on request. Script 01 also needs the UN M49 region layers (Subregions and intermediate_regions) from the United Nations Geospatial geoportal, saved as shapefiles in a folder UNM49-map in the project root. Script 01 makes Figure 2 (Fig_2a, Fig_2b, Fig_2c, Figure_2.tiff, Figure_2.eps), Script 02 makes Figure 3 (Fig_3_ncp_path_split.png, Figure_3.eps), Script 03 makes Figures S1.2 to S1.4 of Supplementary File S1.
Open data_analysis.Rproj in RStudio and run the scripts in order; outputs are written to the project root.
